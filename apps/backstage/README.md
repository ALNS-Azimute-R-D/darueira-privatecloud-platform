# Backstage Developer Portal

## Overview
Spotify Backstage Internal Developer Portal (IDP) instance for the Darueira Private Cloud Platform.

## Responsibilities
- Software Catalog for all platform services, APIs, and libraries.
- Golden Path Software Templates for rapidly scaffolding polyglot microservices (Java 25, Kotlin, Go, TypeScript/React).
- TechDocs documentation rendering directly from repository markdown files.
- Integrations:
  - Authentik OIDC Authentication
  - OpenFGA ReBAC Authorization Plugin
  - Kubernetes / MicroK8s cluster plugin
  - Tekton CI Pipeline viewer
  - ArgoCD deployment status plugin
  - Central MinIO storage for TechDocs static assets
  - Central PostgreSQL for Backstage database persistence
